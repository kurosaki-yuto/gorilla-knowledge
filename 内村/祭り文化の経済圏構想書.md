## 第1章　祭りの現実

### 商品力は圧倒的である

阿波踊りは400年の歴史を持つ。毎年約123万人が訪れる。徳島市の試算によれば、2023年の経済波及効果はわずか2日分で約25億円。4日間フル開催なら約42億円と推計されている。  
阿波踊りは、間違いなく「強いコンテンツ」である。  
しかし、その巨大な価値を生み出している張本人である踊り手たちの現実は、まったく違うものだ。

### 踊り手の懐事情：踊るほど赤字になる

| お金が出ていくもの | 実際の状況 |
|---|---|
| 衣装・楽器 | 連全体で数十万～百万円。足袋や下駄も自費 |
| 練習場所 | 確保が難しく、料金も高い。公共施設の抽選頻り |
| 移動費・遠征費 | 全部自負担。徳島→大阪だけでも数万円かかる |
| 運営費 | 会費だけでは足りず、不足分はメンバーの自腐 |

収入はどうか。年間15回以上の出演機会があるが、ほとんどが数万円以下。依頼は口コミや知り合い経由で、組織的に仲介する仕組みはない。踊りは「イベントの添え物」として安く買われている。  
踊れば踊るほど、衣装は傷み、交通費がかさみ、練習場代が飛ぶ。「踊るほど赤字になる」。これが、阿波踊りの担い手の現実である。

### 運営側も苦しい

阿波踊りの運営団体である徳島市観光協会は、4.2億円の借金を抱え、最終的に2018年に破産した。120万人が訪れる大イベントなのに、万年赤字。東洋経済はこの構造を「イベント地獄」と呼んだ。  
2024年の阿波踊りは3年連続黒字を達成し、総収入は約3.5億円になった。しかしこれは「運営」の話であって、踊り手には1円も渡っていない。42億円の経済効果を生んでいるのは踊り手なのに、そのお金は宿泊や飲食に流れ、踊り手は無償で足袋をすり減らしている。

### 放置すれば、祭りは消える

この問題を放置すると、以下の悪循環が加速する。

1. 担い手が稼げない（踊るほど赤字）
2. 若い人が入ってこない（始め方もわからない）
3. 担い手が高齢化する
4. 技術や文化の継承が途絶える
5. 祭りが消滅する

これは仮Dの話ではない。2024年、岩手県で千年続いた「蓇民祭」が幕を閉じた。担い手の高齢化で「もう準備ができない」という理由だった。2023年を最後に消えた祭りは、全国で少なくない。

## 第2章　なぜこうなるのか

第1章で見た現実は、阿波踊りに限った話ではない。日本全国に約30万あるとされる祭りの多くが、同じ構造的問題を抱えている。  
では、なぜ祭りの担い手は稼げないのか。ここで、同じ「人を感動させる技芸」でありながら、ちゃんと稼げている世界と比べてみたい。スポーツと音楽だ。

|  | スポーツ（NPB） | 音楽 | 祭り |
|---|---|---|---|
| まとめる団体 | NPB（日本野球機構） | レコード会社 | なし |
| チーム | 12球団 | レーベル所属 | 各連がバラバラ |
| 個人のファン | 選手にファンがつく | アーティストにファン | 担い手の認知≈ゼロ |
| TV・配信 | 放映権で数百億円 | Spotify等 | なし |
| スポンサー | 球団単位で大型契約 | ツアー協賛等 | 単発数万円 |

プロ野球選手が野球だけで生活できるのは、NPBという統括団体があり、放映権があり、スポンサーがあるからだ。ミュージシャンが音楽だけで食べていけるのは、Spotifyやライブハウス、レコード会社という仕組みがあるからだ。  
つまり、スポーツや音楽には「技芸をお金に変える仕組み」（＝経済インフラ）がある。祭りには、これが一切ない。  
祭りで稼げないのは、祭りの力が足りないからではない。稼ぐための仕組みが存在しないからである。

### 今あるインフラは「小さすぎる」

阿波踊りにインフラが完全にないわけではない。連協会的な団体は存在する。しかしそこに経済的な機能がない。

- 出演依頼をつなぐ窓口が整備されていない
- 踊り手の評価やランク付けの仕組みがない
- 「踊りを始めたい」人がどこに行けばいいかわからない

協会はあるが経済機能がない。出演機会はあるが組織化されていない。担い手はいるが個人として認知されていない。すべてが「あと少し」足りない。その「あと少し」の総体が、経済インフラである。

### なぜ「今」なのか：3つの追い風

1. SNSの成熟。個人の担い手にファンがつく仕組みを、InstagramやTikTokで作れる時代。NPBが140年かけたファン基盤構築を、圧縮できる。
2. インバウンド需要。訪日外国人が求める「Matsuri」は、単価を一気に引き上げる外部からのお金の流入口になる。
3. 企業の文化支援意識の高まり。「文化支援で地域ブランドが向上した」と答える企業が54.9%。レッドブルがマイナースポーツを育ててブランドを作ったように、祭りを育てることが企業の価値を高める時代が来ている。

## 第3章　構想：祭り文化の経済圏

### 目指す姿

「祭り文化機構」——NPBが野球にやっていることを、祭りにやる。  
阿波踊りを起点に、将来的には日本中の祭りを包含する経済圏を構築する。そのインフラの本体は、「祭りのすべてが集まる専用アプリ」である。

### アプリの5つの機能

アプリには5つの機能があり、それぞれが連動して回る。

1. イベント検索・予約（祭り版ホットペッパー）。ファンは地域・日程・ジャンルで祭りイベントを探し、そのままチケットを購入できる。
2. 担い手プロフィール・ランキング。各イベントに出演する担い手の個人ページがあり、動画・経歴・ファン数・評価が見える。イベントごとのランキングも表示される。
3. ファン機能。推しの担い手をフォローし、応援コメントや投げ銭を送れる。ファンの数と熱量が可視化されることで、担い手の「市場価値」が目に見えるようになる。
4. マッチング。企業や依頼主がアプリで担い手を検索し、ランキング順に発注できる。実績と評価が溺まるほど単価が上がる設計。
5. 育成・入口機能。「祭りを始めたい」人がアプリから連やチームを見つけて参加できる。担い手の供給源になり、高齢化問題を根本から解決する。

この5つはバラバラではなく、お互いの燃料になる設計だ。イベントで注目された担い手のプロフィールにファンが集まり、ファンが增えた担い手にマッチング案件が来る。マッチングで実績が付いた担い手は次のイベントでさらに注目される。1つが回ると他の4つも加速する。

### お金の流れ

この経済圏には3つのプレイヤーがいる。ファン、担い手、企業。真ん中に運営（祭り文化機構）がいて、全員をつなぐ。

- ファン → 運営：チケット代・体験料。アプリでイベントを見つけて予約・購入する。
- 企業 → 運営：スポンサー費・文化支援費・マッチング発注費。
- 運営 → 担い手：出演料・マッチング報酬。担い手は踊ることに集中するだけでお金が入る。
- 担い手 → ファン：感動・体験という価値。ファンはそのお返しに投げ銭やグッズ購入で担い手を直接応援できる。
- 運営 → 企業：ブランド露出・CSR実績という価値を返す。

### それぞれのプレイヤーが得るもの

- 担い手：「踊るほど赤字」から解放される。興行の出演料、マッチング報酬、ファンからの投げ銭・グッズ収入。個人にファンがつき、「プロの祭り人」がキャリアになる。
- ファン：年間を通じて祭りを楽しめる。推しの担い手を応援できる。「祭りの季節だけ」が日常になる。
- 企業：サントリーが音楽を育ててブランドを作り、レッドブルがスポーツを育ててライフスタイルブランドになったように、祭りを育てることが企業価値を高める。
- 運営：チケット手数料、マッチング仲介手数料、スポンサー費。イベントが增えるほど実績が積まれ、スポンサー単価も上がり、マッチング案件も增える。スケールする構造。

## 第4章　収益モデル

### アプリの4つの収益源

| 収益源 | 仕組み | 例 |
|---|---|---|
| チケット手数料 | ファンがアプリでイベント予約。代金の×%を取得 | チケット5,000円 × 10% = 500円/枚 |
| マッチング仲介 | 企業がアプリで担い手に発注。成約額の×%を取得 | 成約10万円 × 15% = 1.5万円/件 |
| 担い手プレミアム | 基本無料。有料で上位表示・分析機能等 | 月額980円～のプレミアムプラン |
| 投げ銭・グッズ手数料 | ファンが推しに投げ銭・グッズ購入。×%を取得 | 1,000円投げ銭 × 20% = 200円 |

### 各プレイヤーの負担

|  | ファン | 担い手 | 企業 |
|---|---|---|---|
| アプリ利用 | 無料 | 基本無料 | 検索・閲覧無料 |
| 課金タイミング | チケット購入時に手数料込 | マッチング成約時に手数料 | 発注時に成約手数料 |
| 任意課金 | 投げ銭・グッズ | プレミアム月額 | スポンサー契約 |

全プレイヤーの参入障壁がゼロであることが重要。お金が発生するのは「価値が動いた瞬間」だけ。チケットが売れたとき、マッチングが成約したとき、投げ銭が飛んだとき。

### 収益源が太くなる順番

最初から全部を回すのではなく、成長に合わせて順番に太くする。

- 初期：チケット手数料。自主イベントを打つたびにここで売上が立つ。
- 実績後：マッチング仲介。企業案件が回り始める。
- ユーザー増後：プレミアム課金。担い手のニーズが明確になってから。
- 文化定着後：投げ銭・グッズ。ファン文化が根付いてから。

## 第5章　誰が使うのか

### ファン側：3つの層

#### Layer 1：体験ハンター（訪日外国人の個人旅行者）

「京都で茶道、大阪で祭り」のように、日本文化体験を旅の目的にする層。ViatorやAirbnb Experienceで「Japan traditional」を検索する。1人5,000～15,000円を払える。最も単価が高く、最初に獲得すべきターゲット。

#### Layer 2：カルチャーファン（日本文化に深い関心を持つ海外在住者）

アニメ・和食・武道などから日本に入り、祭りに興味を持つ層。まだ訪日していないが、SNSでフォローし、投げ銭やグッズを購入する。アプリのファン機能のメイン利用者。訪日時にはLayer 1に転換する。

#### Layer 3：ローカルファン（国内の祭り好き・在日外国人）

地元の祭りに毎年行く層、大阪在住の外国人で日本文化に触れたい層。イベントの安定的なリピーターになる。

### 企業側：4つのパターン

- A. インバウンド事業者（旅行会社・ツアーオペレーター・OTA）。訪日ツアーに「祭り体験」を組み込みたい。アプリで担い手を検索し、ツアー日程に合わせて発注する。月に複数件の継続案件になりうる。
- B. ホスピタリティ企業（ホテル・旅館・クルーズ船）。宿泊客や乗客への特別体験として祭りを提供したい。「ホテルのロビーで阿波踊り」「クルーズ船内で祭り体験」など。1回の単価が高く、定期契約になりやすい。
- C. 地元企業（大阪・徳島の中小企業）。取引先の接待、社内イベント、CSRスポンサー。地域密着で関係が長期化しやすい。
- D. 自治体・観光協会。観光コンテンツとして祭り体験を活用したい。インバウンド誘致の施策として補助金を出す可能性もある。直接の顧客というよりパートナー。

### 市場規模感（ざっくり試算）

2024年の訪日外国人は約3,600万人。そのうち約15%が体験消費にお金を使う。大阪訪問率は約40%。つまり、大阪で体験を探している外国人は年間約216万人。そのうち1%が祭り体験に参加するとすると、約2.2万人。単価5,000円として、大阪のインバウンド体験市場だけで年間約1.1億円規模。ここにマッチング・スポンサー・国内ファンを加えると数倍になる。

## 第6章　仮説検証プラン

阿波踊りの学生チーム（阪大連・22名）を起点に、以下のフェーズで進める。各フェーズの移行条件をクリアしたら次へ進む。

### Phase 0：SNSで反応を検証する

**やること：** 阪大連の練習・出演を撮影し、Instagram Reelsで英語キャプション付きで発信。10投稿で反応パターンを見る。同時に簡易LP（ウェイティングリスト）を自作して設置。  
**検証する仮説：** 阿波踊りのコンテンツに海外から反応があるか。どのフォーマットが伸びるか。ウェイティングリストに登録する人はいるか。  
海外からの反応が一定数確認できたら、Phase 1へ。

### Phase 1：最初の有料イベントを打つ

**やること：** 阪大連で大阪市内にて「阿波踊り体験イベント」を開催。ターゲットは体験ハンター（Layer 1）。Viator / Airbnb Experience / Instagram広告で集客。1人5,000円 × 20名 = 10万円で損益分岐を確認。  
**検証する仮説：** チケットに5,000円払う外国人はいるか。どのチャネルから集客できるか。参加者の満足度はどうか。  
黒字で完走し、参加者の満足度が高ければ、Phase 2へ。

### Phase 2：MVPプラットフォーム + 企業マッチング

**やること：** 自作でMVPプラットフォームを構築。イベント一覧・担い手プロフィール・予約機能を最小限で実装。同時にPhase 1の実績をもとに、ホテル・旅行会社・クルーズ船に営業開始。  
**検証する仮説：** プラットフォーム経由で予約は入るか。企業はいくら払うか。定期案件になるか。  
企業案件が複数成約し、プラットフォーム経由の予約が発生したら、Phase 3へ。

### Phase 3：他の学生チームを巻き込む

**やること：** 他大学の阿波踊りサークル、よさこいサークルに声掛け。「登録すれば出演案件が来る」と実績ベースで誘う。プラットフォームにランキング機能・ファンフォロー機能を追加実装。  
**検証する仮説：** 実績を見せれば他チームは参加するか。担い手が增えると案件数も比例して增えるか。ランキングが担い手のモチベーションになるか。  
複数チームが稼働し、ネットワーク効果が確認できたら、Phase 4へ。

### Phase 4：アプリ正式リリース + 拡大

**やること：** ネイティブアプリに移行。投げ銭・グッズ機能を追加。社会人の連にも展開。阿波踊り以外の祭り団体にも声をかけ始める。  
**検証する仮説：** アプリ化で利用頻度が上がるか。投げ銭は定着するか。阿波踊り以外の祭りにもモデルは通用するか。  
ここが「祭り文化機構」の正式スタート地点。
