# 録画指示書（松本さん用）

**録画方法**: `Cmd + Shift + 5` → 画面収録 → 操作 → 停止
**音声**: 不要（AIナレーションを後から被せます）
**解像度**: そのままでOK（自動で1920x1080に調整します）

---

## P-02 用デモ（1本撮る）

### デモ①: Geminiで最初の1枚を生成（目安2〜3分）
1. gemini.google.com を開く
2. プロンプト入力欄に以下を入力:
   ```
   仕事効率化をテーマにしたInstagram投稿用の画像を作成してください。

   20代ビジネスマン向け
   未来感のある雰囲気
   青と白を基調

   中央に人物、背景はデジタル表現
   正方形
   ```
3. 送信して生成を待つ（待ち時間もそのまま録画でOK）
4. 生成された画像を表示
5. 画像をクリックしてダウンロードボタンを見せる

**ファイル名**: `P02_demo1_first_image.mov`
