### 動画① P-01用：Manusの全体像デモ

> **スライド12の直後に挿入**
> 「では実際に見てみましょう」の後

**撮るもの：**

1. manus.im を開く（トップ画面を数秒映す）
2. プロンプト入力欄に何か1つタスクを入力する
   - 例：「日本のSaaS市場の主要プレイヤー5社を比較表にまとめて、Excelで納品してください」
3. Enterを押す
4. Manusが計画を立てるところ（Plannerのステップ分解が見える）
5. 「Manus's Computer」画面に切り替わるところ
6. ブラウザが動いてWebを巡回している様子（数秒でOK）
7. 完成通知が出る
8. 成果物をダウンロードする
9. ダウンロードしたファイル（Excel等）を開いて中身を数秒映す

**目安：2〜3分**（待ち時間は後で早送り編集）

### 動画② P-02用：リサーチ実演

> **スライド12の直後に挿入**
> 「では実際にやってみましょう」の後

**撮るもの：**

1. manus.im のプロンプト入力画面
2. 以下のようなリサーチプロンプトを入力：
   ```
   従業員100名規模の企業向けに、日本語対応のプロジェクト管理ツール上位5社
   （Asana, Monday.com, Backlog, Notion, Jira）を比較調査してください。
   比較軸：月額料金/無料枠の有無/日本語サポート/主要機能/導入実績。
   Excel比較表と、1ページの推薦レポート（PDF）で納品してください。
   ```
3. Enterを押す → Manusの計画画面
4. 「Manus's Computer」でWebを巡回する様子
   - 各ツールのサイトにアクセスしている様子が映ると最高
5. 完成通知
6. Excelファイルをダウンロード → 開く → 比較表が出来ているところ
7. PDFもダウンロード → 開く → レポートが出来ているところ

**目安：3〜4分**

### 動画③ P-03用：データ分析実演

> **スライド12の直後に挿入**
> 「では実際にやってみましょう」の後

**事前準備：**
- 適当なCSVファイルを1つ用意する（売上データ、アンケート結果、何でもOK）
- なければ、ChatGPTに「サンプルの売上データCSV（12ヶ月分、商品名・カテゴリ・数量・単価・地域の列）を作って」と頼んで生成

**撮るもの：**

1. manus.im を開く
2. CSVファイルをドラッグ&ドロップ（またはアップロード）
3. 以下のようなプロンプトを入力：
   ```
   添付のCSVは過去12ヶ月の売上データです。
   以下の分析をお願いします：
   ①月別売上推移グラフ ②カテゴリ別売上構成比（円グラフ）
   ③地域別売上ランキングTOP5 ④前月比成長率の推移
   グラフ付きPDFレポートと、ピボット付きExcelで納品してください。
   ```
4. 「Manus's Computer」画面でPythonコードが実行される様子
   - ターミナルにpandasやmatplotlibが動いているのが映ると最高
5. グラフが生成される瞬間（見えたら）
6. 完成通知
7. PDFレポートをダウンロード → 開く → グラフが入っているところ
8. Excelをダウンロード → 開く → ピボットテーブルが出来ているところ

**目安：3〜4分**

### 動画④ P-04用：制作物（LP）実演

> **スライド12の直後に挿入**
> 「では実際に作ってみましょう」の後

**撮るもの：**

1. manus.im のプロンプト入力画面
2. 以下のようなプロンプトを入力：
   ```
   架空の製品「SmartTask Pro」のランディングページを作成してください。
   構成：①ヒーローセクション（キャッチコピー＋CTAボタン）
   ②3つの主要機能紹介 ③料金プラン比較表（3プラン）
   ④お客様の声3件 ⑤問い合わせフォーム
   デザイン：モダン、青系カラー、レスポンシブ対応。
   公開URLを共有してください。
   ```
3. 「Manus's Computer」でHTML/CSS/JSが書かれていく様子
4. プレビューが表示される瞬間
5. 公開URLをクリック → ブラウザでLPが表示される
6. ページをスクロールして全体を映す
7. **（できれば）フィードバック修正：**
   - 「CTAボタンの色をオレンジに変更してください」と追加指示
   - 修正が反映されるところ

**目安：3〜4分**
