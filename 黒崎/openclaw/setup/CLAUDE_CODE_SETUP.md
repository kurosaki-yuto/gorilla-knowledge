# 🤖 Claude Code セットアップ プロンプト

## 使い方

以下の「セットアップコマンド」をコピーして、Claude Code の入力欄に貼り付けてください。

すると Claude が自動で質問を聞いて、セットアップを完了してくれます。

---

## 📋 セットアップコマンド

**以下をそのままコピーして Claude Code に貼り付けてください：**

```
🚀 OpenClaw クラウドソーシング自動エージェント セットアップ

以下の設定をヒアリングして、自動でセットアップしてください：

【ユーザー情報】
1. このセットアップを実行するマシンのOS は何ですか？（macOS / Linux / Windows+WSL2）
2. Python がインストールされていますか？（はい / いいえ）
3. Homebrew がインストールされていますか？（はい / いいえ）

【クラウドワークス】
4. クラウドワークス のメールアドレスは？
5. クラウドワークス のパスワードは？

【ココナラ】
6. ココナラ のメールアドレスは？
7. ココナラ のパスワードは？

【優先設定】
8. クラウドソーシングで対応したい案件タイプは？（複数可：AI開発 / 営業代行 / マーケティング / その他）
9. 自動返信の最小単価は？（例：20000 円）
10. 監視頻度は？（例：60 分ごと）

【Notion連携（オプション）】
11. Notion API を使いたいですか？（はい / いいえ）
    - はい の場合：Notion API Key は？
    - はい の場合：Notion Database ID は？

【セットアップ最終確認】
12. セットアップを実行してもよろしいですか？（はい / いいえ）
    - はい の場合：自動でセットアップ実行
    - いいえ の場合：キャンセル

---

【セットアップタスク】
上記の回答をもとに、以下を自動実行してください：

1. ✅ OS・環境チェック
   - Python バージョン確認
   - 必要なツールのインストール確認

2. ✅ ディレクトリ確認
   - ~/Downloads/開発/addness-knowledge/kurosaki/openclaw/crowdsourcing-agent が存在するか確認
   - 存在しない場合はエラー出力

3. ✅ Python 仮想環境作成
   - venv フォルダ作成
   - 依存パッケージインストール（selenium, requests, beautifulsoup4, python-dotenv）

4. ✅ .env ファイル生成
   - 回答内容をもとに .env ファイルを自動生成
   - 以下の形式：
     ```
     CLOUDWORKS_EMAIL=user@example.com
     CLOUDWORKS_PASSWORD=password
     COCONALA_EMAIL=user@example.com
     COCONALA_PASSWORD=password
     MONITOR_INTERVAL_MINUTES=60
     AUTO_RESPOND_MIN_BUDGET=20000
     AUTO_RESPOND_CATEGORIES=AI開発,営業代行,マーケティング
     NOTION_API_KEY=xxx（Notion使用時のみ）
     NOTION_DATABASE_ID=xxx（Notion使用時のみ）
     ```

5. ✅ ログディレクトリ作成
   - logs/ フォルダ作成

6. ✅ 実行権限設定
   - run.sh に実行権限付与（chmod +x）

7. ✅ 完成メッセージ出力
   - セットアップ完了ログ
   - 次の実行コマンド表示：
     ```
     cd ~/Downloads/開発/addness-knowledge/kurosaki/openclaw/crowdsourcing-agent && ./run.sh
     ```

---
```

## 💡 使い方の流れ

### **Step 1：上のセットアップコマンドをコピー**

上の「セットアップコマンド」をすべてコピーしてください。（``` から ``` まで）

### **Step 2：Claude Code に貼り付け**

Claude Code の入力欄に貼り付けます。

### **Step 3：Claude が質問を開始**

Claude が自動で質問を聞きます。

```
🤖 Claude:
「このセットアップを実行するマシンのOS は何ですか？」

👤 あなた:
「macOS」

🤖 Claude:
「Python がインストールされていますか？」

👤 あなた:
「はい」

... （以降、質問が続きます）
```

### **Step 4：セットアップ完了**

全質問に答えると、Claude が自動でセットアップ実行＆完成メッセージを表示。

## 📝 別の例：カスタム設定用

もし「デフォルト設定でいいから、すぐ実行したい」という場合は、以下を使用：

```
🚀 クイック実行（デフォルト設定）

以下のデフォルト値でセットアップを実行します：

- 対応案件：AI開発, 営業代行, マーケティング
- 最小単価：20000円
- 監視頻度：60分ごと
- Notion連携：なし

【入力が必要：】
1. クラウドワークス のメール
2. クラウドワークス のパスワード
3. ココナラ のメール
4. ココナラ のパスワード

上記4つだけ教えてください。残りはデフォルトで設定します。
```

## 🔧 トラブル時

セットアップ中に問題が出た場合、Claude が自動で対応方法を提示します。

例：
```
❌ Python 3.8 以上がインストールされていません。

対策：
以下を実行してください：
   brew install python3

その後、セットアップを再実行してください。
```
