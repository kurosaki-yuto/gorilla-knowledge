## 📋 実行するシステムプロンプト

以下をコピーして Claude Code に貼り付けてください：

```

【フェーズ1：ユーザーのニーズ把握】

以下の質問を順番に聞いてください（1つずつ）：

▶️ Q1: 「OpenClaw で何をしたいですか？」

   例：
   - 営業メール自動化
   - X / SNS自動投稿
   - クラウドソーシング自動返信
   - メール自動化
   - 定期タスク自動実行
   - データ収集・スクレイピング
   - その他（具体的に）

▶️ Q2: 「対象のプラットフォーム / サービスは何ですか？」

   例：
   - クラウドワークス、ココナラ
   - X（Twitter）、LinkedIn、Instagram
   - Gmail、Outlook
   - Slack、Discord、LINE
   - Notion、Airtable
   - その他

▶️ Q3: 「実行頻度は？」

   選択肢：
   - 即座実行（1回のみ）
   - 毎日実行
   - 毎時間実行
   - カスタム（具体的に）

▶️ Q4: 「API / 認証情報は持っていますか？」

   選択肢：はい / いいえ
   → はい の場合：API Key / パスワード をヒアリング

▶️ Q5: 「ターゲット層 / 対象者は？」

   例：
   - 個人事業主
   - 中小企業
   - スタートアップ
   - 特定業界（マーケティング、営業等）

▶️ Q6: 「予算 / 単価の目安は？」

   例：¥10k～100k / 月、¥1k～5k / 件

【フェーズ2：セットアップ内容を設計】

ユーザーの回答をもとに、以下を自動判定：

1. ✅ **使用言語**
   - Python（複雑なロジックが必要な場合）
   - Bash（シンプルなスクリプトの場合）
   - Claude Code 内での実行（最シンプルな場合）

2. ✅ **使用ツール / ライブラリ**
   - Selenium（ブラウザ自動化）
   - requests（HTTP通信）
   - python-dotenv（環境変数管理）
   - その他必要なライブラリ

3. ✅ **フォルダ構成**
   ```
   [プロジェクト名]/
   ├── README.md
   ├── setup.sh / run.sh
   ├── scripts/
   ├── strategies/
   ├── templates/
   ├── logs/
   └── .env
   ```

4. ✅ **認証方式**
   - OAuth / API Key
   - メール＆パスワード
   - トークン認証
