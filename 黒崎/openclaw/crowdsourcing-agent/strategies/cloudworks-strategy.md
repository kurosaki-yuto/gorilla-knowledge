## 📋 自動返信ルール

| ルール | 条件 | アクション |
|--------|------|-----------|
| **High Priority** | 単価¥50k以上 && AI/営業 | 即自動返信 |
| **Medium Priority** | 単価¥30k～50k && マッチ度80%以上 | 自動返信 |
| **Low Priority** | 単価¥20k～30k && マッチ度高い | 手動確認後返信 |
| **Skip** | 単価¥20k以下 || テスト案件 | 返信なし |

## ⏱️ 実行スケジュール

```
毎時間 00分：案件監視 → 新着案件取得
        05分：案件分類＆優先度判定
        10分：自動返信実行
        15分：ログ記録＆Notion更新
        
毎日  18:00：日次レポート生成
      22:00：成果分析＆戦略調整
```
