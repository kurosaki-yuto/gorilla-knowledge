# アップセル面談スクリプト v1

## 使い方
面談中にこのスクリプトを横に置いて進行する。全部やる必要はない。相手の温度に合わせて取捨選択。

---

## Phase 1: 信頼構築（最初の5分）

### 30秒自己紹介（固定）
```
黒崎と申します。アドネス株式会社で、AI開発とDXコンサルをやっています。
最近は中小企業向けにAIツールの開発・導入支援をメインでやっていて、
RAGシステム、業務自動化、チャットbot開発あたりが得意分野です。
本日はよろしくお願いします。
```

### 相手を知る3問（必須）
1. **「今回の案件、どういう背景で出されたんですか？」**
   → 表面的な要件の裏にある本当の課題を掘る
   → 「前任が辞めた」「社長が急にAI使えと言い出した」等の本音が出る

2. **「御社の中で、この案件の意思決定は〇〇さんがされるんですか？」**
   → 決裁者かどうかを確認。担当者なら「決裁者にも同席いただけると話が早い」

3. **「他にも何社か比較検討されてますか？」**
   → 競合状況の把握。「初めて外注する」ならチャンス大

---

## Phase 2: 案件深掘り + 差別化提案（10-15分）

### ヒアリングの鉄則
- **相手に7割喋らせる**（自分は3割）
- **メモを取る姿を見せる**（真剣に聞いてるアピール）
- **「他には？」を3回繰り返す**（1回目の回答は表面的）

### 深掘り質問リスト

**課題の深さを測る質問:**
- 「この業務、今は誰がどうやってますか？」
- 「それにどれくらい時間かかってますか？」
- 「それが解決したら、一番何が変わりますか？」
- 「これまでに似たような取り組みはされましたか？」

**予算・スケジュールの確認:**
- 「予算感はどのくらいで考えてますか？」（ストレートに聞く）
- 「いつまでに使えるようにしたいですか？」
- 「まず小さく始めて検証、というアプローチはありですか？」

**技術環境の確認:**
- 「今使ってるツール・システムは何ですか？」
- 「社内にエンジニアやIT担当の方はいらっしゃいますか？」
  → **「いない」が最高の回答。丸ごと任せてもらえる可能性大**

### 差別化ポイント（競合との違いを出す）
- 「AIの実装だけじゃなく、業務設計から一緒にやれます」
- 「プロトタイプを1-2週間で出して、使ってみてから本格開発する進め方です」
- 「Claude Codeという最新ツールを使って、開発スピードが通常の3-5倍です」

## Phase 3: アップセル布石（5-10分）★最重要

### 4パターン質問法
案件タイプに応じて、以下のいずれかの質問を自然に投げる:

#### パターン1: 横展開型（同じ仕組みを別部署/別業務に）
```
「ちなみに、これが上手くいったら他の部署でも同じような課題ありますか？」
「例えば営業チームだけじゃなく、カスタマーサポートでも使えそうですね」
```

#### パターン2: 深掘り型（今回の案件をもっと本格的に）
```
「今回はまずプロトタイプですが、本格運用するとなるとどんな機能が必要ですか？」
「将来的にはデータ分析やレポート自動生成もあると便利そうですね」
```

#### パターン3: 顧問型（継続的な相談役として）
```
「御社のAI活用、これ1件で終わりじゃなくて色々やりたいこと出てきそうですよね」
「月額で技術顧問として入って、都度相談いただく形もありますよ」
```

#### パターン4: パッケージ型（複数課題をまとめて）
```
「今お聞きした課題、実は全部つながってて、まとめて解決した方が効率いいです」
「個別に3件発注するより、パッケージで月額契約の方がコスパいいですよ」
```

### アップセル布石の鉄則
- **初回面談でアップセルを売り込まない**（信頼がない状態で押すと逃げる）
- **種を蒔くだけ**（「そういうこともできるんだ」と思ってもらう）
- **初回納品物の品質で勝負**（期待を超える→「もっと頼みたい」が自然に出る）

## Phase 4: クロージング + 面談後アクション（5分）

### クロージングトーク
```
「ありがとうございます。今日お聞きした内容で、具体的な進め方をまとめてお送りします。
 まず[小さな成果物]を1-2週間で作って、使ってみていただく形でいかがですか？
 見積もりは明日中にお送りしますね。」
```

### 面談直後アクション（24時間以内）
1. **お礼メッセージ送信**（面談後30分以内）
   ```
   本日はお時間いただきありがとうございました。
   お話しいただいた[課題]について、具体的な進め方をまとめています。
   明日中にお見積りとあわせてお送りしますので、少々お待ちください。
   ```
2. **見積もり・提案書作成**（UPSELL_PROPOSAL.mdのテンプレ使用）
3. **パイプライン更新**（PIPELINE.mdのステージ移動）
4. **2-3日後フォローアップ設定**

## 案件タイプ別 深掘り方向表

| 案件タイプ | 深掘り方向 | アップセルの種 |
|---|---|---|
| AI chatbot | 対応チャネル拡大（LINE/Web/Slack）| 全チャネル統合bot + 分析ダッシュボード |
| 業務自動化 | 他の手動業務のリストアップ | 全社業務自動化プロジェクト |
| LP/HP制作 | マーケ施策全体 | LP→集客→CRM→分析の一気通貫 |
| データ分析 | 定期レポートの自動化 | 分析基盤構築 + 月次レポート自動生成 |
| AI導入相談 | 全社のAI活用ロードマップ | 技術顧問契約（月額） |
| スクレイピング | データ活用方法 | データ基盤 + 分析ダッシュボード |
| PM/PMO | プロジェクト全体の課題 | 開発チーム丸ごと請負 |

---

## 危険信号（この案件は深追いしない）

- 「とりあえず安く試したい」→ 値引き要求が止まらないパターン
- 「前の業者がダメだった」を3回以上言う → クレーマー気質
- 面談に5人以上出てくる → 意思決定が遅い
- 「NDA先に結んでから」→ 話が進まないパターン（小案件なら特に）
- 要件が毎回変わる → スコープクリープ地獄
