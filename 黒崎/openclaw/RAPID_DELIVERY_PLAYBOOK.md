# 爆速納品プレイブック v1

## コンセプト
Claude Codeを最大活用し、通常2-4週間の案件を3-5日で納品する。品質は妥協しない。スピードで信頼を勝ち取り、アップセルにつなげる。

## Claude Code活用の鉄則

### 速度を上げるテクニック
1. **プロジェクト初期化はテンプレから**（毎回ゼロから作らない）
2. **並列エージェントで同時作業**（フロント/バック/テストを並列）
3. **既存コードの再利用**（過去案件のコンポーネントを流用）
4. **小さく作って見せる**（完璧を目指さず、動くものを早く出す）
5. **フィードバックループを短く**（Day 3-4でクライアントに見せる）

### やってはいけないこと
- 完璧主義（80%の品質で早く出す方が100%で遅いより価値がある）
- 過剰な設計（3-5日の案件に設計書に2日かけるのは本末転倒）
- 技術選定で悩む（迷ったらNext.js + Tailwind + Vercel。これで9割カバー）
- 一人で全部やろうとする（Claude Codeに任せられることは全部任せる）

## 品質チェックリスト（納品前の最終確認）

### 基本品質
- [ ] 要件の全項目が実装されている
- [ ] レスポンシブ対応（モバイル/タブレット/PC）
- [ ] エラーハンドリング（ユーザー向けエラーメッセージ）
- [ ] ローディング状態の表示
- [ ] 基本的なSEO設定（title/description/OGP）

### セキュリティ
- [ ] 環境変数でAPIキー管理（.envに直書きしない）
- [ ] 入力バリデーション
- [ ] XSS/SQLインジェクション対策
- [ ] CORS設定
- [ ] 認証が必要な箇所に認証を実装

### デプロイ
- [ ] 本番環境で動作確認
- [ ] SSL証明書（HTTPS）
- [ ] エラー監視設定（Sentry等、必要に応じて）
- [ ] バックアップ手順の確認

### ドキュメント
- [ ] README.md（セットアップ手順）
- [ ] 環境変数一覧（.env.example）
- [ ] 使い方の簡易マニュアル（スクショ付き）
- [ ] 管理者向け運用手順（必要に応じて）

### 納品物
- [ ] ソースコード（GitHubリポジトリ or ZIP）
- [ ] デプロイ済みURL
- [ ] アカウント情報一覧（管理画面等）
- [ ] 簡易マニュアル
