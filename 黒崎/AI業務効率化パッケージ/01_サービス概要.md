# AI業務効率化 サービス概要

**業務改善コンサル・研修・伴走支援・環境設定の4本柱＋必要に応じた受託開発。外部の専門家が組織に入り、「自社だけでAIが回る状態」まで導くパッケージ型サービスです。**

---

## 1. よくある「AI活用の壁」

### 「使える人」と「使えない人」の差が広がっている
- 詳しい人だけがAIをバリバリ使って、周りは置いてけぼり
- その人が抜けたら、ノウハウごと消える

### どこにAIを入れればいいか、社内で判断できない
- ツールは配ったけど、現場は「自分の仕事のどこに使えるの？」で止まっている
- 結果、議事録の要約くらいで活用が止まる

### AIを「賢い検索エンジン」としか使えていない
- 質問して回答をもらう、それだけの使い方になっている
- AIがリサーチ、資料作成、データ分析、メール対応、画像・動画生成まで自動化できることを知らない
- AIエージェントが自律的にタスクを実行する時代に、「チャットで質問」以上の使い方を知らない

### セキュリティ・ルールが追いついていない
- 「これAIに入れていいんだっけ？」の判断が個人任せ
- 権限管理のルールがない
- 怖いから全面禁止、の会社も多い

## 2. 本サービスの全体像

AIを組織に定着させるには、「研修だけ」「ツール導入だけ」ではうまくいきません。本サービスは以下を **一つのパッケージ** として提供します。

### ① 業務改善コンサル

**何を解決するか：** 「AIを入れたいけど、どこに入れればいいかわからない」

業務フローを一緒に見て、「どこにAIを入れると一番効くか」を数値で特定。優先順位つきのロードマップを作る。経営層向けROIレポート、AI活用のルール設計まで含む。

### ② 研修

**何を解決するか：** 「AIを使いこなせる人が社内にいない」

既存の動画研修ライブラリ（ChatGPT / Claude / Gemini / Perplexity / Manus 横断）を組織のレベルに合わせてカスタマイズ配信。部門別ワークショップで「自分の仕事のどこに当てはめるか」を実際にやる。社内トレーナーも育成。**Claude Code / Claude API 等の開発者向け専門コースも順次拡充中。**

### ③ 伴走支援

**何を解決するか：** 「研修しても組織に定着しない」（**本サービス最大の差別化ポイント**）

AI活用の専門家が3〜6ヶ月にわたり継続的に伴走支援で対応させていただきます。チャットサポートで日常の質問に即レス、週次定例で振り返り、現場から出る「これも自動化できない？」をその場で一緒にやってみせる。月次レポート、経営層報告、社内トレーナー育成まで。**「専門家が継続的に関わる」から定着する。**

> ご要望があれば、常駐・半常駐での対応も可能です（別途ご相談）

### ④ 環境設定

**何を解決するか：** 「**Claude Code / Cursor / GitHub Copilot** を社内で使いたいけど、設定方法がわからない」

開発者向けAIツール3種（Claude Code / Cursor / GitHub Copilot）の導入・設定をまるごと引き受けます。インストール、IDE連携、プロジェクト設定テンプレートの配布、権限ルールの統一、実用的な使い方のセットアップまで。**チーム全員が同じ環境で、同じ品質でAIを使える状態** にします。

### ⑤ 受託開発（必要に応じて）

**何を解決するか：** 「社内ではどうしても作れない案件が出てきた」

伴走中に「社内では対応が難しい」と判断した開発案件を受託。要件定義から設計・開発・納品、引き継ぎまで行う。**プレミアムプランには月1件までの受託案件が含まれます。**

## 3. サービスの進め方

```
 STEP 1               STEP 2                  STEP 3             STEP 4
 業務改善コンサル  → 研修 ＋ 環境設定      → 伴走支援         → 自走

どこにAIを入れるか    使える人を育てる        人が入って現場に   社内だけで
を見つける           動く環境を整える         定着させる         回せる状態へ

                          ＋ 受託開発（社内でできない部分は持ち帰って開発）
```

### まず決めること（業務改善コンサル）
- 「うちはAIをこう使う」という方針 — 経営層が旗を振る
- AI活用のルール — 「何をAIに入れていい？何がダメ？」を明文化
- どのツールを使うか — ChatGPT / Claude / Gemini / Perplexity 等、目的別に最適な組み合わせ
- 最初に試すチーム、効果測定の指標

### 環境を整える（環境設定）
- **Claude Code / Cursor / GitHub Copilot の導入・初期設定**
- IDE連携、プロジェクト設定テンプレートの配布
- チーム全員が同じ環境で使えるよう標準化
- プロンプトテンプレート集の整備

### 研修で学ぶ
- 全社員向け：AIリテラシー研修（基礎、主要AIツールの使い分け）
- 部門別：業務別ワークショップ
- 実務者向け：AIエージェント活用
- 社内トレーナーの育成

### 定着させる（伴走支援）
- 専門家が3〜6ヶ月にわたり継続的に伴走支援で対応
- 週次定例、チャットサポートで日常の疑問に即レス
- 現場の「これも自動化できない？」をその場で解決
- 月次レポートで効果を可視化

## 4. なぜ今、このサービスなのか

### 日本企業のAI活用は、大きく遅れている

生成AIを「活用している」と答えた日本企業はわずか **17.3%**、業務に正式に組み込めている企業は **24%**、「期待を上回る効果」を実感しているのは **10%** だけ。今行動しないと、差はさらに開きます。

### 「どこに入れるか」を見つけるだけで、劇的に変わる

多くの会社が「ツールを配って終わり」にしています。でも一番効くのは、**業務を俯瞰して「ここにAIを入れると一番効く」を見つけること**。本サービスは最初に必ず「業務改善コンサル」を入れるので、無駄打ちがありません。

### ツールは1つじゃない。目的別に最適な組み合わせを

ChatGPT、Claude、Gemini、Perplexity、Manus——それぞれ得意分野が違います。特定のベンダーに縛られず、お客さんの業務に最適な組み合わせを提案します。**Claude Code / Claude API 等、開発者向けの専門領域も順次拡充中** で、エンジニアチームの高度な活用にも対応できます。

### 研修だけでは定着しない。**専門家が継続的に関わる**から定着する

本サービス最大の差別化ポイントは「伴走支援」。AI活用の専門家が3〜6ヶ月にわたり継続的に対応させていただきます。チャットサポートで日常の質問に即レス、週次定例で困りごとを解消、現場で一緒に手を動かす。「研修して終わり」ではなく、専門家が継続的に入るから、本当に定着する。

### 半年かけて「自走」まで持っていく

AIリテラシーを組織に根付かせ、社内だけで自走できる状態まで持っていくには **最低3ヶ月、推奨は半年**。3ヶ月では「使えるようになった」で終わります。半年あれば、研修 → 現場定着 → 社内トレーナー独り立ち、までたどり着けます。
