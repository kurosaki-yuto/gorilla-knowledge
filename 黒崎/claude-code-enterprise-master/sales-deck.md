# Claude Code 企業導入マスター講座

---

## 1. 今、多くの企業が抱えている「AI活用の壁」

### 「使える人」と「使えない人」の差が広がっている
- 詳しい人だけがAIをバリバリ使って、周りは置いてけぼり
- その人が抜けたら、ノウハウごと消える
- 「あの人に聞かないとわからない」がずっと続いている

### 何をどう学べばいいか、誰もわからない
- YouTubeやブログをなんとなく見てるだけで、体系的に学べていない
- 「とりあえずChatGPTっぽく使ってみる」で止まっている
- 誰が・何を・どの順番で学ぶべきか、社内で整理されていない

### AIを「賢い検索エンジン」としか使えていない
- 質問して回答をもらう、それだけの使い方になっている
- AIがコードを書いて、テストを実行して、Gitにコミットまでできることを知らない
- エージェント型AI・MCP・サブエージェントといった次世代の使い方が完全に未知の領域

### セキュリティ・ルールが追いついていない
- 「これAIに入れていいんだっけ？」の判断が個人任せ
- AIが書いたコードの品質チェック体制がない
- 権限管理や監査ログの仕組みが整っていない

## 3. 企業に導入するとき、何が必要？

### まず決めること

- **「うちはAIをこう使う」という方針** — 経営層が旗を振る。現場任せにしない
- **セキュリティのルール** — 「何をAIに入れていい？何がダメ？」を明文化する
- **どのプランを使うか** — Claude Pro / Max / Enterprise、自社に合うものを選ぶ
- **APIキーの管理方法** — 誰がどう管理するか、シークレットマネジャーの導入
- **最初に試すチーム** — まずは3〜5人のパイロットチームで小さく始める
- **効果をどう測るか** — レビュー時間、PR作成速度、バグ修正時間など、「before/after」で比べられる指標を決めておく

### 環境を整える

- **セットアップ手順書** — 誰でも迷わず環境構築できるドキュメントを作る
- **IDE連携** — VS Code や JetBrains の拡張機能をチーム全員に配布
- **CLAUDE.md テンプレート** — リポジトリに「AIへの申し送り事項」を置く仕組み
- **権限モードのルール** — どこまでAIに自動実行させるか、チームで統一する
- **社内ツールとの接続** — MCPでSlack・Jira・社内DBなどとつなぐ準備
- **ネットワーク確認** — プロキシやファイアウォールで通信がブロックされないか事前に検証

### 研修で学ぶ

- **全社員向け：AIリテラシー研修** — 「Claudeの基本操作」+「AIとの付き合い方」をベースに（1〜2週間）
- **エンジニア向け：Claude Code基礎〜実践** — 「はじめの一歩」→「実践活用」の順で（2〜4週間）
- **リーダー向け：高度機能** — 「MCP入門〜応用」/「サブエージェント入門」/「エージェントスキル入門」/「Claude APIで作るAIアプリ」
- **理解度チェック** — 各フェーズ後にテストやハンズオン課題
- **社内トレーナーの育成** — 外部に頼らず社内で教え合える体制をつくる

### 定着させる

- **「うちのベストプラクティス集」を作る** — パイロットチームで見つけた良い使い方を全社に共有
- **社内スキルライブラリ** — よく使うAIの「型」をSKILL.mdにまとめてチームで使い回す
- **社内MCPサーバーの開発** — 自社システムとAIを直接つなぐ基盤を内製する
- **月次レポート** — 使われているか？効果が出ているか？を定期的に可視化
- **段階的に広げる** — パイロット → チーム → 部門 → 全社、焦らず順番に

## 4. なぜ今、Claude Code なのか

### 「チャット」じゃない。AIが「手を動かす」時代になった
従来のAIは「質問したら答えが返ってくる」だけのもの。Claude Codeは違う。ファイルの読み書き、コードの生成・修正、テストの実行、Gitへのコミット、外部APIの呼び出し——これらを全部AIが自分で実行する。人間は方向性を示すだけ。開発の生産性が根本的に変わる。

### 社内ツールとAIをつなぐ「MCP」という武器
MCP（Model Context Protocol）はオープンな接続規格。Slack・Jira・社内DB・CI/CDなど、いま使っているツールとAIをプラグインのように接続できる。特定のベンダーに縛られず、自社で自由に拡張できるのが強み。

### 体系的な学び方で、チーム全員を引き上げる
入門から応用まで、全17コースの一貫したカリキュラム。誰が・何を・どの順番で学ぶかが明確だから、「詳しい人だけが使える」状態にならない。全社員のAIリテラシーからエンジニアの高度活用まで、段階的にレベルアップできる。

### 個人のノウハウを「チームの資産」にできる
Claude Codeには、個人が見つけた良い使い方をチーム全員で共有する仕組みが最初から入っている。SKILL.mdでAIの「型」を標準化、CLAUDE.mdでプロジェクトの記憶を引き継ぎ、サブエージェントでタスクを分担。「あの人しか使えない」を構造的になくせる。

### AWSでもGCPでも、今のインフラのまま使える
Amazon BedrockにもGoogle Vertex AIにも対応。クラウド戦略を変えなくてもそのまま導入できる。オンプレ要件がある場合もAPI経由で対応可能。「インフラを変えなきゃいけない」というハードルがない。
