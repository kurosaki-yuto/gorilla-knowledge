## 提供サービス

### 1. RAGチャットbot・AIアシスタント開発
社内文書検索、FAQ自動応答、ドキュメントQAシステムの構築。
LangChain・Difyを活用したRAGパイプラインの設計から実装まで。

### 2. 業務自動化ツール開発
レポート自動生成、外部API連携、Slack/LINE通知など、
手作業を削減するワークフロー自動化ツールの開発。

### 3. AI実践研修（3日間カリキュラム）
ChatGPT / Claude / Cursor / GitHub Copilot を活用した3日間カリキュラム。
非エンジニアでも業務にAIを取り入れられる実践型プログラム。

### 4. Webアプリ開発
Next.js / Firebase / Supabase によるフルスタック開発。
管理画面・業務ツール・顧客向けWebサービスなど。

### 5. DXコンサルティング
業務フロー分析から始め、本当に効果のある施策だけを提案。
いきなり構築ではなく、費用対効果を最大化するAI導入設計。

## 実績

### プライム上場企業

- **日立建機** — AI検査項目作成システムの構築・提案。RAGによる社内ドキュメント検索基盤を開発。

### 製造業・建設業

- **信和工業** — 製造スケジュールPDFを自動処理するWebアプリを開発（Next.js + Python Flask）。
- **複数社** — AI実践研修の企画・実施。ChatGPT / Claude を業務に導入する実践型カリキュラムを提供。

### マーケティング・業務支援

- **マーケライン** — Lステップ設計図の自動化、業務支援ツール導入。

- 求人自動スカウトシステム — 候補者マッチング・自動メッセージ送信の仕組みを構築。
