# FigmaとUI設計

## 概要
Figma AIやFigma Makeを活用したデザイン生成、Figma MCPによるClaude Codeとの連携など、Figmaを中心としたUI設計ワークフローに関するナレッジ集。
デザインからコード変換、デプロイまでの一気通貫フローや、公式Skills・プラグインの活用法を収録。

## ツール・サービス
| 名前 | 概要 | URL |
|------|------|-----|
| Figma AI | Figma公式のAI機能。テキストからプロ品質のデザインを生成可能 | https://www.figma.com/ |
| Figma Make | AIチャットで高精度なWebデザインを作成し、コード書き出しまで対応 | https://www.figma.com/ |
| Figma MCP | FigmaとClaude Codeを接続するプロトコル。デザインデータを直接参照してコード実装が可能 | - |
| Figma公式 Claude Codeプラグイン | Code Connect、デザインシステム生成などのSkillsを含む公式プラグイン | - |
| Kombai | Figmaデザインの再現度が高いコード変換ツール | https://www.kombai.com/ |

## 知見・ナレッジ

### Figma AIによるデザイン生成
- テキストから数分でプロ顔負けのデザインを作成可能
- スライド作成にも対応し、テンプレートや素材が豊富
- Claude 3.5と比較すると柔軟性では劣るが、本家デザインツールとしての品質は高い
- 出典: @masahirochaen (https://x.com/masahirochaen/status/1806812401557557705)

### Figma Makeで個人開発のMVPを高速作成
- AIとは思えないクオリティのデザインを生成
- ファイルダウンロードまたはFigma MCP経由でClaude Codeにデザインを渡してそのまま実装可能
- AIコーディングで最も難しいデザイン部分をカバーする優秀なツール
- 出典: @taiyo_ai_gakuse (https://x.com/taiyo_ai_gakuse/status/1987081635318440437)
- 出典: @masahirochaen (https://x.com/masahirochaen/status/2004909344916439298)

### Figmaから直接デプロイ
- Figmaから直接デプロイできるプラグインが登場
- 簡単なLP作成ならペライチやStudioが不要になる可能性
- 出典: @taiyo_ai_gakuse (https://x.com/taiyo_ai_gakuse/status/1807078195872899399)

### Figma公式Skills（Claude Code連携）
- Figma公式がデザインをコードに精度よく変換するためのSkillsを公開
- 3つのSkills: Code Connect、デザインシステムルール生成、デザイン参照コード実装
- Skillsを使用することでデザイン再現精度が向上
- 出典: @yusuke_post (https://x.com/yusuke_post/status/2004132626530291885)
- 出典: @yusaku_0426 (https://x.com/yusaku_0426/status/2008751491960697216)
