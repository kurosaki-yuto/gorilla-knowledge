# 自己啓発・マインドセット

## 概要
成長マインドセット、思考フレームワーク、人間心理、行動原理に関するブックマーク集。
イーロン・マスクの成功方程式から承認欲求の仕組み、システム思考、AI時代の意識論まで、
自己成長と世界理解を深めるための多角的な知見がまとめられている。

## 知見・ナレッジ

### 成功・成長のための思考フレームワーク
- イーロン・マスクが若者に伝えた「勝つための方程式」。若い社会人が知っておくべき成功の原則。
  - 出典: @antiaging_all (https://x.com/antiaging_all/status/1845932298002485346)
- 「バカと天才の違い」を生む爆速成長フレームワーク「システム思考」。物事を構造的に捉えることで成長速度が変わる。
  - 出典: @mikami_01 (https://x.com/mikami_01/status/1799629344169660668)
- タスク処理には「順算」と「逆算」の2つのプロセスがある。初めてのことは順算（手探り）、経験済みのことは逆算（ステップ実行）で進める。
  - 出典: @mikami_01 (https://x.com/mikami_01/status/1816748758396493969)
- 「Connecting the dots」の実践論: 客観で座標を確定し、主観の価値で向きと強さを定め、最小行動で一歩出て、再観測で軌道修正する。
  - 出典: @AI_masaou (https://x.com/AI_masaou/status/1956680690646540753)

### 目標達成と行動力
- 目標に対して最大出力のエネルギーを長期的に発揮し続けるには「自己矛盾の解消」が不可欠。自分の価値観と目標・行動の方向性を一致させることが重要。
  - 出典: @mikami_01 (https://x.com/mikami_01/status/1846757743673450716)
- コンスタントに結果を出す人の特徴は、行動一つ一つの目的が明確であること。「なぜ今これをするのか？」に明確な答えがあるので、ブレずに挑戦し続けられる。
  - 出典: @marcy_sns (https://x.com/marcy_sns/status/1826442489538159101)
- 「行動できない原因」を三菱総合研究所が分析。人は「やり始めるとき」と「やり続けたことを止めるとき」にストレスを感じる。AIにサポートしてもらい客観的に人生を進める方法。
  - 出典: @satori_sz9 (https://x.com/satori_sz9/status/1852912949561815451)
- バーニングニーズを見つけたら、DeepResearch→プロダクト制作→Xでニーズ調査→繰り返し→MVP投下のサイクルを徹底してやり切ることが大事。
  - 出典: @taiyo_ai_gakuse (https://x.com/taiyo_ai_gakuse/status/1992817042400113103)

### 組織・リーダーシップ
- 組織のビジョンに対する姿勢の7段階: コミットメント→参画→心からの追従と段階がある。仕組み自体を作り出すレベルが最高段階。
  - 出典: @mikami_01 (https://x.com/mikami_01/status/1816356740763631648)
- 「部下に任せるより自分でやった方が早い」に対するサイバーエージェント藤田晋会長の回答。任せることの本質的な重要性。
  - 出典: @kkatada (https://x.com/kkatada/status/2001449675988308197)
- 人に期待するのではなく、共通の目的を達成することに期待をするのがベスト。互いに期待し合うのではなく、目的志向で協力する。
  - 出典: @mikami_01 (https://x.com/mikami_01/status/1817768683487592662)

### 人間心理・自己理解
- 承認欲求の仕組み: 人は自分が価値を感じるものにしか、価値を感じてもらっても嬉しいと思わない。自己肯定感が低い人がいくら褒められても上がらない理由。
  - 出典: @satori_sz9 (https://x.com/satori_sz9/status/1860252790842667407)
- 人間の発達とは「複雑な世界をよりありのままに尊重し、受容するためのプロセス」。世界をありのままに受容できれば、人生をより肯定的に捉えられる。
  - 出典: @mikami_01 (https://x.com/mikami_01/status/1829037878141432128)
- 忘れられた記憶は「勘」という形で選択に影響を与え続ける。ベルン大学の研究で、忘れた記憶の集合体が無意識的な勘となって助けていると判明。
  - 出典: @NazologyInfo (https://x.com/NazologyInfo/status/1935329652618432557)
- ChatGPTの過去チャット履歴を全参照して「無意識に繰り返す致命的なミス」と「無自覚な成功パターン」を分析するプロンプトで自己理解が深まる。
  - 出典: @marcy_sns (https://x.com/marcy_sns/status/1913935727949197743)

### 世界観・哲学的思考
- 世界の真理に近づくための100ステップ。世界は複雑で多面的であり、人間の知覚には限界があるという前提から始まる思考の体系。
  - 出典: @satori_sz9 (https://x.com/satori_sz9/status/1834775738895220845)
- 世界の力学を正しく理解し、自分に影響する範囲からスタートして広く理解・制御していく。内面も外面も果てしなく広く探求できる。
  - 出典: @mikami_01 (https://x.com/mikami_01/status/1820292402852266279)
- 理想の自分になる方法と仕事ができる考え方の両方が手に入る、広く使える思考が学べる書籍の紹介。
  - 出典: @Book_Meyer (https://x.com/Book_Meyer/status/1849025675010654487)

### AI時代の視座
- AIの優位性は課題解決能力の高低だけでなく「意識の有無」が重要。非線形な変化が起こるかどうかは意識の有無で決まる。
  - 出典: @mikami_01 (https://x.com/mikami_01/status/1870833234088796203)
- 数学的な計算の時代から意味的な計算の時代への過渡期。この転換を理解できワクワクできる人材が求められている。
  - 出典: @mikami_01 (https://x.com/mikami_01/status/1839568754247901418)
- Apple社の論文「The Illusion of Thinking」: AIは高度な問題への対応になるほど思考精度が急激に低下し、AGI実現は困難との示唆。
  - 出典: @kemohure (https://x.com/kemohure/status/1932447289186079201)

### 謙虚さ・自省
- 自分が舐めていたこと・人達がすごく偉大で大きいものだったと日々実感。社会人経験なく「逃げ」でこの世界に来た人間が「本気の人々」に勝てるわけがない。
  - 出典: @Pien_Alchemist (https://x.com/Pien_Alchemist/status/1889599062967722299)
- パクられることへの向き合い方。冷静に考えることの重要性。模倣される側の心構え。
  - 出典: @mikami_01 (https://x.com/mikami_01/status/1990645448420569297)
