# その他自動化ツール

## 概要
AI時代における業務自動化・ワークフロー構築に関するツールやノウハウをまとめたカテゴリ。
AAAモデル（AI Automation Agency）、RPA、X(Twitter)自動化、議事録自動化、Google Workspace Flows等、多様な自動化手法がカバーされている。
AIコンテンツ運用やAntigravity等の新興ツールに関する知見も含む。

## 知見・ナレッジ

### AAAモデル（AI Automation Agency）
- リアム・オットリー（25歳、プログラミング知識ゼロ）が2.5年で年商10億円を達成
- 「AIの指揮者（コンダクター）」として技術ではなく課題解決にポジションを取る
- ノーコードツール（Botpress・n8n等）を組み合わせて企業の業務自動化を提供
- 日本のAI導入率は28.4%（2025年12月時点）で、特に地方中小企業にチャンスがある
- 出典: @kumataro_design（AAA事例研究）

### SaaS産業の変革とAIエージェント
- ユーザー体験はエージェントとの対話に移行し、バリューはAPI経由で提供される時代へ
- サム・アルトマンは「特定スキルを教えるAIチューター」と「人生の全てを理解したエージェント」に価値を見出している
- 出典: @kubotamas (https://x.com/kubotamas/status/1851188894647337241, https://x.com/kubotamas/status/1853793992233857157)

### Google Workspace Flows x GAS連携
- appsscript.jsonに定義を追加してデプロイすることで、GASをWorkspace Flowsのプロセスに組み込める
- スタンドアロンで動いていたGASをプロセスの中で活用できるようになる
- 出典: @r__morita (https://x.com/r__morita/status/1984741457014767638)

### RPA（ロボティック・プロセス・オートメーション）
- GrokでX上の話題を全出力し、Geminiで自動画像生成するRPAシステムの事例
- 手動操作のストレスポイントを特定して自動化することが成功の鍵
- 出典: @unikoukokun (https://x.com/unikoukokun/status/1992829281047900530)

### X(Twitter)自動化・コンテンツ運用
- Xboostでブックマーク読み込み → AIリライト → 自動CTA設定のワークフロー
- AIコンテンツ運用は「AI生成前提で面白い」か「AIと気づかれずにパフォーマンスが出る」の2パターン
- AI丸出しの生成物にはビジネス価値がつかない
- 出典: @taishiyade (https://x.com/taishiyade/status/2001578356551131142, https://x.com/taishiyade/status/2007655140854218887)

### 議事録自動化
- 個人開発でマネタイズを狙うなら「議事録自動化プロダクト」が最短ルート
- Zoom録画 + Whisperの組み合わせが有効
- 出典: @taishiyade (https://x.com/taishiyade/status/2002152141289390366)

### Antigravityの活用Tips
- AIルールを設定ファイルに記載するとそのルールに従って回答してくれる
- グローバルルールは全プロジェクトに適用可能
- 日本語で回答させたい場合はルール設定が必要
- 出典: @AI_LowCode (https://x.com/AI_LowCode/status/1995115608623743229)

### AI時代のマインドセット
- 流れが早い時代だからこそ、長期間取り組める課題を見つけることが重要
- トレンドに一喜一憂せず軸をぶらさないことが成功の鍵
- 出典: @taishiyade (https://x.com/taishiyade/status/2026779439858655456)
