# Google Gemini

## 概要
Google が提供する大規模マルチモーダル AI「Gemini」に関するブックマーク集。
リアルタイム情報を活用したマルチモーダル機能、スライド資料の自動生成、CLI / GitHub Actions 連携、画像生成AI「Nano Banana 2」など、Gemini エコシステムの活用事例と最新ニュースをまとめている。

## ツール・サービス
| 名前 | 概要 | URL |
|------|------|-----|
| Gemini on Multimodal Canvas | リアルタイム情報を活用した無料のマルチモーダル体験機能 | https://gemini.google.com/ |
| Marp Web Editor | Gemini と組み合わせてスライド資料を一瞬で作成できるツール | https://web.marp.app/ |
| Gemini CLI GitHub Actions | GitHub Actions 上で `@gemini-cli` として呼び出せる CLI 連携機能 | https://github.com/google-gemini/gemini-cli |
| Nano Banana 2 | Pro 品質を Flash 速度で実現する Google の新画像生成 AI（512px〜4K対応） | https://deepmind.google/technologies/imagen/ |

## 知見・ナレッジ

### マルチモーダル活用
- Gemini on Multimodal Canvas により、リアルタイム情報に基づく高精度なマルチモーダル処理が無料で利用可能
- 出典: @taiyo_ai_gakuse (https://x.com/taiyo_ai_gakuse/status/1808512026400186421)

### スライド資料の自動生成
- Gemini と Marp Web Editor を組み合わせることで、台本付きのスライド資料を短時間で作成できる
- 出典: @riku720720 (https://x.com/riku720720/status/1829126860053041507)

### Gemini CLI / GitHub Actions 連携
- Gemini CLI が GitHub Actions に対応し、`@gemini-cli` で呼び出し可能に
- CI/CD パイプラインへの AI 統合が容易になった
- 出典: @sora19ai (https://x.com/sora19ai/status/1952917978951106754)

### 画像生成 AI「Nano Banana 2」
- Pro 品質を Flash 速度で実現する新しい画像生成モデル
- 512px〜4K 対応、キャラクター一貫性は最大5人まで
- Gemini アプリ / 検索 / Flow に一斉展開、Flow では無料利用可能
- 出典: @masahirochaen (https://x.com/masahirochaen/status/2027058891335635310)
