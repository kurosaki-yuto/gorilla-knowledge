# v0・Bolt・UI生成

## 概要
Vercel v0やBoltなどのAI UI生成ツールに関するブックマーク集。
プロンプトからフロントエンドUIを自動生成し、開発効率を飛躍的に高める手法やツール連携のナレッジをまとめる。

## ツール・サービス
| 名前 | 概要 | URL |
|------|------|-----|
| Vercel v0 | プロンプトからフロントエンドUI/コードを生成するAIツール | https://v0.dev/ |
| Bolt | システムの土台とUIを自然言語から生成するAIサービス | https://bolt.new/ |
| Cursor Composer | AIによるコード編集・生成機能を備えたエディタ | https://cursor.sh/ |
| Dify | バックエンド構築向けのノーコードAIプラットフォーム | https://dify.ai/ |

## 知見・ナレッジ

### v0の再現性を高める量産手法
- v0とCursor Composerで納得いくまで制作し、成果物をベースプロンプトとして保持する
- ベースプロンプト + 追加要件定義で、高クオリティの制作物を再現性高く量産できる
- 出典: @swarm_ai_cloud (https://x.com/swarm_ai_cloud/status/1828408229615071254)

### AIツール5選によるフルスタック開発
- Bolt（土台とUI生成）、v0（フロントエンド）、Dify（バックエンド）、Cursor（微調整）、o1（バグ修正）の5ツール構成
- これらを使いこなすことでレガシー開発者からAIエンジニアへ転換できる
- 出典: @satori_sz9 (https://x.com/satori_sz9/status/1845753843260571865)
