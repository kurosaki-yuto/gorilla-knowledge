# 動画生成AIツール

## 概要
動画生成AI（Sora、Runway Gen-3、Kling、Luma、Vidu等）に関するブックマーク31件のまとめ。
ツールの比較・性能検証・活用テクニックに加え、AI開発全般（Dify、Claude Code、n8n等）の自動化ノウハウも含む。
2024年6月〜2026年1月にかけて収集された情報で、動画生成AIの急速な進化を時系列で追える。

## 知見・ナレッジ

### Sora / Sora2
- Sora2は招待コード（例: F9K2DM）による利用開始が話題に
- 同一プロンプトでRunway Gen-3と比較検証され、性能差が明確に
- 出典: @shino_business (https://x.com/shino_business/status/1973664318437920837)
- 出典: @ryo_kun0811 (https://x.com/ryo_kun0811/status/1806985824002875652)

### Runway Gen-3 Alpha
- Soraを差し置いて一部で早期アクセスが開始された
- 隠し機能として「自分の声に合わせた動画生成」が可能
- 同じプロンプトでのSoraとの比較で高い評価を獲得
- 出典: @shota7180 (https://x.com/shota7180/status/1807247703732290007)
- 出典: @taiyo_ai_gakuse (https://x.com/taiyo_ai_gakuse/status/1808126550380106097)

### Luma (Dream Machine)
- Luup機能が非常に強力で、MV制作にも活用可能
- Midjourney（画像）+ Claude（台本）+ CapCut（編集）+ Artlist（音楽）との組み合わせで1時間程度でMV全編制作可能
- 出典: @Kohaku_NFT (https://x.com/Kohaku_NFT/status/1816810501369921642)

### Vidu
- Klingよりも優れた性能と評価される動画生成AI
- 最大の特徴はAPIが利用可能なこと
- 出典: @taiyo_ai_gakuse (https://x.com/taiyo_ai_gakuse/status/1818165659119063426)

### AI動画制作のワークフロー
- MV制作例: 動画生成（Luma）+ 画像生成（Midjourney）+ 台本（Claude）+ 編集（CapCut）+ 音楽（Artlist）
- 全編AIで制作して約1時間で完成可能
- 出典: @Kohaku_NFT (https://x.com/Kohaku_NFT/status/1816810501369921642)

### 動画編集のコツ
- 演者の喋りのリズムと編集のリズム（テロップ・カット）を一致させることが重要
- リズムがあべこべだと視聴者の頭に入ってこない
- 出典: @Pien_Alchemist (https://x.com/Pien_Alchemist/status/1840506209717432502)

### Dify活用ノウハウ
- Difyの本質はワークフローではなくチャットフロー
- v1.0.0-beta1でプラグインシステムと新Agentノード導入
- 変数を使いこなすには「変数の概念を抽象化する」能力が必要
- 出典: @sora19ai (https://x.com/sora19ai/status/1885796861480759575)
- 出典: @sora19ai (https://x.com/sora19ai/status/1877352280812310908)

### Claude Code活用
- Taskエージェント + Skills機能の組み合わせが強力
- mobile-mcpでシミュレーター操作が可能になり、開発効率が10倍に
- 並列開発して最良の結果を抽出し、作業記録をドキュメント化する手法が有効
- Riveを使えばDuolingo風のUIアニメーションを実現可能
- 出典: @sora19ai (https://x.com/sora19ai/status/2013205000432890169)
- 出典: @sora19ai (https://x.com/sora19ai/status/2007667452814209477)

### AI開発フロー
- v0 → Bolt → Cursor → Vercel/Cloud Run の流れが推奨
- Vibe Codingでは並列開発 → 最良抽出 → 作業記録のドキュメント化 → 次サイクルで参考にする手法
- Skillsは3種類（Foundational / Partner / Enterprise）を分けて設計することが重要
- 出典: @sora19ai (https://x.com/sora19ai/status/1844172242634281229)
- 出典: @sora19ai (https://x.com/sora19ai/status/1939001668127072380)

### 生成AIエンジニアへの学習パス
- ChatGPTで何でも試す → コードインタープリターでExcel/パワポ生成 → GPTsで仕組み化（Difyも有効）→ Make で自動化
- 出典: @sora19ai (https://x.com/sora19ai/status/1883354068229489043)
